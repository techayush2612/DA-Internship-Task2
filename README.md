# DA-Internship-Task2
Data Visualization and Storytelling using Power BI
Task 2 – Data Visualization and Storytelling

Project Overview

This project focuses on analyzing sales data and presenting meaningful insights using interactive data visualizations.

Tool Used

- Microsoft Power BI

Dataset

- Superstore Sales Dataset

Dashboard

The Power BI dashboard provides an overview of sales performance through different charts, KPIs, and filters.

Key Visualizations

- Total Sales, Total Profit, Total Quantity and Order Count
- Category-wise Sales Analysis
- Monthly Sales Trend
- Segment-wise Sales Analysis
- Region-wise Profit Analysis
- Sales vs Profit Analysis
- Interactive filters for Year, Segment, Region and Category

Key Insights

1. Technology is one of the major contributors to overall sales.
2. The dashboard helps compare sales performance across different customer segments.
3. Sales trends can be analyzed month-wise to identify changes in performance.
4. Regional analysis helps identify differences in profit contribution.
5. Sales and profit are not always directly proportional, so both metrics need to be analyzed together.

Conclusion

The project demonstrates how Power BI can be used to transform raw sales data into interactive visualizations and meaningful business insights. The dashboard makes it easier to understand sales, profit, quantity, customer segments and regional performance.
